# Mi web

Proyecto básico de ejemplo para organizar archivos de texto en un repositorio.

## Contenido

- `archivo1.txt`: contiene texto de prueba.
- `archivo2.txt`: contiene texto de prueba.
- `README.md`: documentación del proyecto.

## Uso

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en tu editor de código.
3. Consulta o modifica los archivos `.txt` según tus necesidades.

## Requisitos

No se necesitan dependencias ni instalaciones adicionales.
